# docs 目录说明

本目录存放项目协作、实验规范、阶段计划、失败分析和答辩材料。所有成员在开始写代码或整理数据前，都应该先阅读这里的规范文档。

## 必读文档

| 文档 | 作用 |
| :--- | :--- |
| `environment_and_git_rules.md` | 环境管理、uv 使用、Python 版本、Git 分支、提交信息、Pull Request 规范 |
| `directory_rules.md` | 项目目录怎么用，哪些文件能提交，哪些文件不能提交 |
| `collaboration_workflow.md` | 每天怎么同步、每周怎么验收、组长怎么检查进度 |
| `team_roles.md` | 三名成员的固定分工、近期任务和交付物 |
| `experiment_notes.md` | 每天实验记录、运行命令、结果文件和问题记录 |

## 后续会继续补充的文档

| 文档 | 作用 |
| :--- | :--- |
| `project_plan.md` | C0-C4 实验主线、阶段计划、每阶段验收标准 |
| `data_description.md` | 知识库材料、测试集字段、数据冻结说明 |
| `evaluation_plan.md` | 指标定义、人工评分规则、消融实验安排 |
| `failure_cases.md` | 至少 10 个失败案例及原因分析 |
| `demo_script.md` | 现场 Demo 固定问题、展示流程和备用方案 |
| `final_report_outline.md` | 结题报告提纲 |
| `slides_outline.md` | 答辩 PPT 提纲 |

## 使用原则

1. 重要决定写进文档，不只在群里说。
2. 每个阶段结束后更新一次实验记录。
3. 测试集、Prompt、配置和实验结果一旦冻结，必须在文档里说明冻结版本。
4. 所有最终报告结论都要能追溯到数据、日志、结果表或失败案例。
