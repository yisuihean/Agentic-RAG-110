# 实验记录

本文档用于记录每天的实验进展、运行命令、结果文件和遇到的问题。它不是流水账，而是后续写结题报告、失败分析和复现实验的重要依据。

---

## 一、记录原则

1. 每次运行重要脚本后都要记录。
2. 只要改了数据、Prompt、配置或模型，就要记录。
3. 失败也要记录，不能只记成功结果。
4. 记录必须写清楚输入、命令、输出文件和问题。
5. 不要把 API Key 写进记录。
